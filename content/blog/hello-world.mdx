这个博客基于以下技术构建：

- **Next.js 16** — React 全栈框架
- **Velite** — MDX 内容编译

- **Shiki** — 代码语法高亮

### 一段代码示例

```ts
// Velite 的 schema 定义
export default defineConfig({
  collections: {
    posts: {
      pattern: "blog/**/*.mdx",
      schema: s.object({
        title: s.string(),
        date: s.isodate(),
        content: s.markdown(),
      }),
    },
  },
});
```
