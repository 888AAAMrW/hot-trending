# 图片资源

替换规则：保持**文件名不变**，直接覆盖即可生效。不需要改任何代码。

| 文件 | 尺寸建议 | 用途 |
|------|---------|------|
| `avatar.png` | 256×256 px，1:1 方形 | 左侧圆形头像 |
| `background-desktop.png` | 1920×1080 px，横屏 | 桌面端全屏背景 |
| `background-mobile.jpg` | 750×1334 px，竖屏 | 移动端全屏背景 |

## 替换步骤

1. 准备好你的图片
2. 重命名为上面对应的文件名
3. 放到这个文件夹里，覆盖原文件
4. 刷新页面即可
